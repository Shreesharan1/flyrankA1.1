# Project Instructions

## Project

This repository is a simple AI-assisted development project.

## Technology

- Node.js
- JavaScript
- Git
- VS Code
- Claude Code

## Coding Conventions

- Write clean and readable code.
- Use meaningful names for variables and functions.
- Avoid unnecessary complexity.
- Keep functions small and focused.
- Add comments only when they improve understanding.

## Git Conventions

Use Conventional Commits.

Examples:

- feat: add new feature
- fix: correct a bug
- docs: update documentation
- chore: update project configuration
  
## Documentation

Keep README.md updated whenever the project setup or usage changes.

## AI Assistant Behavior

Before making changes:

1. Inspect the relevant files.
2. Explain what needs to be changed.
3. Make the smallest reasonable change.
4. Verify the result after making changes.
